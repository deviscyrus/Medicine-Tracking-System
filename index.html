Run it locally

The interactive dashboard runs as a Node.js server and connects to MongoDB. Start both services, then follow these commands in the project folder.

This project page can be shared on GitHub Pages, but the actual app still needs a local Node.js server and MongoDB database to run properly.
  1. Install Node.js 16.20.1 or later.
  2. Start MongoDB.
  3. Install packages: npm install
  4. Start the app: npm start
  5. Open http://127.0.0.1:3000.
